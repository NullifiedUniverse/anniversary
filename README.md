# CryptoLens — Chrome Extension

A polished quality-of-life Chrome extension for crypto traders and enthusiasts.

## Features

- **Highlight Tooltip** — Select any crypto ticker (BTC, ETH, SOLANA…) on any webpage and instantly see price, 24h change, 7d sparkline, market cap, volume, and more
- **Live Watchlist** — Track up to 20 coins with real-time prices and 7-day sparklines
- **Portfolio Tracker** — Enter holdings + avg buy price, see live P&L
- **Fear & Greed Index** — Visual gauge updated in real-time
- **ETH Gas Tracker** — Slow / Standard / Fast gas in Gwei
- **Global Market Stats** — Total market cap, BTC/ETH dominance, 24h volume
- **Price Alerts** — Browser notifications when a coin crosses your target
- **Full Settings Page** — Currency, watchlist, portfolio, alerts, appearance

## Data Sources

| Source | Usage |
|---|---|
| [CoinGecko API](https://www.coingecko.com/en/api) | Prices, charts, search (free, no key) |
| [Alternative.me](https://alternative.me/crypto/fear-and-greed-index/) | Fear & Greed Index |
| [Cloudflare Ethereum RPC](https://cloudflare-eth.com) | ETH gas prices |

## Installation

### 1. Generate Icons

Run once to create the PNG icon files:

```bash
node scripts/generate-icons.js
```

Requires only Node.js (no npm install needed).

### 2. Load in Chrome

1. Open `chrome://extensions`
2. Enable **Developer mode** (top right)
3. Click **Load unpacked**
4. Select this folder

That’s it. The CryptoLens icon appears in your toolbar.

## Usage

### Highlight Tooltip
On any webpage, **select/highlight** text like `BTC`, `ETH`, `Solana`, or `DOGECOIN`. A price card appears after a brief delay showing:
- Current price with sparkline
- 1h / 24h / 7d change
- Market cap, volume, 24h high/low
- ATH reference and CoinGecko link

Press `Escape` or click elsewhere to dismiss.

### Popup
Click the toolbar icon to open the popup:
- **Watchlist tab** — live prices for your tracked coins
- **Portfolio tab** — add holdings and track P&L
- **Market tab** — Fear & Greed, ETH gas, global stats

### Settings
Click the gear icon or right-click the extension → Options:
- Change currency, manage watchlist, add/remove portfolio holdings, set price alerts, adjust appearance

## Privacy

No data is ever sent to any server other than the listed data sources. All user settings and portfolio data are stored locally via `chrome.storage.sync` (synced with your Google account if signed in). No analytics, no tracking.
